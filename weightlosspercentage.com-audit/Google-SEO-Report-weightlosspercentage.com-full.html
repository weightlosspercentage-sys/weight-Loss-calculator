Findings combine technical, content, schema, performance, visual, and search-readiness evidence as available.

  1. Info: CRITICAL: Live site serves stale build — homepage and 22 other pages emit canonical http://localhost:4321 (homepage, /about/, /contact/, /blog/, /calculators/, /nutrition/, /compare/, 3 blog posts + locale variants). dist/dist2 built with wrong site config; dist3 is correct.
  2. Info: CRITICAL: Soft-404s — Cloudflare SPA fallback '/* /index.html 200' returns HTTP 200 with homepage content for any missing URL; /calculators/weight-loss/from-120-to-114/ is a phantom page.

  5. Info: HIGH: Homepage duplicate JSON-LD (2x Organization, 2x FAQPage, 2x WebApplication) risks rich-result suppression.

  2. Move AI-crawler Allow groups above the Cloudflare-managed robots block to unblock GPTBot/ClaudeBot/Google-Extended.
  3. Replace '/* /index.html 200' with '/* /index.html 404' to stop soft-404s.
  4. Add visible author byline, review date, and references section to blog articles.

2. Audit Categories

2.1 Technical SEO

Score: 45/100

What Works

  • Clean single-host redirection (http 301, non-www 301, trailing slash 308)
  • All 120 sampled sitemap URLs return 200
  • HSTS preload, nosniff, frame-options, referrer-policy headers
  • HTTP/3 + Brotli via Cloudflare

Findings

Localhost canonical on 23 pages incl. homepage (stale deploy) Critical

Live curl of / and /about/ shows rel=canonical http://localhost:4321/... and og:url localhost. dist/ and dist2/ were built with site http://localhost:4321; dist3 (current source) is correct. Homepage, /about/, /contact/, /blog/, /calculators/, /nutrition/, /compare/, /blog/postpartum-weight-loss-safe-guide/, /blog/water-fasting-weight-loss/, /blog/weight-loss-plateau/, /calculators/weight-loss/from-120-to-114/ and locale variants affected.

Recommendation: Rebuild (npm run build -> dist3), redeploy from dist3, purge CDN cache. Verify homepage canonical is https://www.weightlosspercentage.com/.

Soft-404s from SPA fallback Critical

Nonexistent URL returns HTTP 200 with homepage content via '/* /index.html 200' in _redirects. /calculators/weight-loss/from-120-to-114/ is a phantom page serving the homepage template.

Recommendation: Change catch-all to '/* /index.html 404' or a real 404 page; keep 200 fallbacks only for locale SPA entry points.

No Content-Security-Policy; Access-Control-Allow-Origin: * High

Security headers otherwise strong but no CSP and a wildcard CORS header on HTML responses.

Recommendation: Add CSP for known third parties (Ezoic, AdSense, GTM/GA4, Clarity, Ahrefs, fonts, Unsplash); remove wildcard ACAO.

Sitemap lastmod static; coverage gaps Medium

All 9 sitemaps report lastmod 2026-07-30 regardless of content. /blog/anti-gravity-exercises-weight-loss/ not in sitemaps; phantom from-120-to-114 listed.

Recommendation: Regenerate lastmod from file mtime on each deploy; add missing article; drop phantom URLs.

2.4 Schema / Structured Data

Score: 75/100

What Works

  • Organization (462), BreadcrumbList (229), FAQPage (154), WebApplication (137), Article (83), MedicalWebPage (83), HowTo (73), Person (92)
  • Detailed Article blocks (author, publisher+logo, dates, mainEntityOfPage)
  • All blocks valid JSON-LD

Findings

Duplicated JSON-LD on homepage High

Homepage emits 2x Organization, 2x FAQPage, 2x WebApplication (identical). 90 pages emit >=6 schema blocks. Cause: parser_v2.ts does not strip JSON-LD from parsed head.

Recommendation: Strip JSON-LD in parser_v2.ts (like canonical) or stop double-injecting; emit a single @graph.

Missing WebSite/SearchAction; brand inconsistency Medium

No WebSite schema; author Person never linked via worksFor; 'WeightLossPercentage.com' vs 'Weight Loss Percentage' naming mismatch.

Recommendation: Add WebSite+SearchAction; unify brand; add Person.worksFor/url.

Schema opportunities unused Low

Glossary (DefinedTermSet), compare pages (FAQPage/Article), nutrition (NutritionInformation) missing.

Recommendation: Add as content ships.

2.6 AI Search Readiness

Score: 70/100

What Works

  • High-quality llms.txt (manifest, licensing, formulas, AI permission)
  • Excellent ai.txt (citation rules, per-calculator accuracy references)
  • Static JS-free content; no paywall; strong schema
  • PerplexityBot/ChatGPT-User/Gemini/cohere/OMgili allowed

Findings

robots.txt blocks major AI crawlers High

Cloudflare-managed block (GPTBot, ClaudeBot, Google-Extended, CCBot, Bytespider, Amazonbot, Applebot-Extended, meta-externalagent) precedes custom Allow groups; first-match wins so they stay blocked despite ai.txt claiming permission.

Recommendation: Move AI crawler Allow groups above the Cloudflare block or remove them from the managed list.

Localhost canonical poisons citations High

Citable URLs resolve to http://localhost:4321 until redeploy.

Recommendation: Redeploy (Technical C1).

Thin locales not citable; placeholder contact Medium

zh/ru pages too thin for AI grounding; en locales near-duplicate. ai.txt contact is a placeholder.

Recommendation: Improve locale content; use a real contact email.
